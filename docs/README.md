# Docs index

| file | what it holds |
|---|---|
| `experiment_log.md` | Every run with its hypothesis, change, command, outcome and failures (newest at the end) |
| `claims_table.md` | Candidate paper claims, each with its status and the evidence for it |
| `paper_outline.md` | Outline of the workshop / benchmark paper |
| `real_data_design.md` | The frozen design of the real-data (tender-level) evaluation |
| `frozen_design_previous.md` | Frozen design of the `previous` variant (locked run 2) |
| `frozen_design_stat_auc.md` | Frozen design of the `stat_auc` variant (locked run 3) |
| `frozen_design_rl_screens.md` | Proposed frozen design of the `rl_screens` variant (no locked run yet) |
| `figures/` | Paper figures (PNG) with their data tables (`data/`) and an index (`README.md`) |

Result files live in `../results/`; raw run output in `../results/logs/`.
`bid_rigging_report_v2.pdf` is the compiled project report. Its editable source is the online
report document; it is not regenerated automatically.
